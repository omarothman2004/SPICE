# SPICE Circuit Simulation Portfolio

## Overview
This repository acts as a central library for various circuit simulations modelled in LTspice. It serves as a reference collection for analysing primarily analogue circuits, such as amplifiers, filters, but also digital elements, including CMOS designs. 

## Included Topologies
- Active & Passive filter networks.
- Linear and switch-mode power supply stages.
- Operational amplifier signal conditioning blocks.

## Simulation Types 
- Depending on the circuit being designed, some circuits may have DC sweep, AC, transient bode plot, or DC Op point analysis performed in software.

## Usage
Clone the repository and open the `.asc` files directly in LTspice to run transient, AC, or DC operating point analyses.
